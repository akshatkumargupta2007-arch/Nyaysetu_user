# Other civic issue (अन्य नागरिक समस्या)

**Category code:** `OTHER_CIVIC` (group: OTHER)

**Definition:** Used only when a complaint is clearly a civic issue but does not
match any specific category above with enough confidence. The model should
set `clarifying_question` whenever it uses this code, so the citizen is asked
one question rather than being silently misrouted.

**Disambiguation:** This is a deliberate escape hatch, not a dumping ground —
try every other category first.
